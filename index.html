Regras de Segurança
⚠️ Cole estas regras no Console Firebase → Firestore → Regras e em Storage → Regras. Sem isso qualquer pessoa pode alterar seus dados.

1. Firestore Rules

Apenas usuários autenticados podem escrever. Qualquer pessoa pode ler (necessário para o site público).

Firestore Security Rules 
// Firebase Console → Firestore Database → Regras
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    // Produtos: qualquer um lê, só admin escreve
    match /produtos/{genero}/items/{prodId} {
      allow read: if true;
      allow write: if request.auth != null;
    }

    // Qualquer outra coleção: somente autenticados
    match /{document=**} {
      allow read, write: if request.auth != null;
    }
  }
}

2. Storage Rules

Apenas usuários autenticados podem fazer upload. Imagens são públicas para leitura.

Storage Security Rules 
// Firebase Console → Storage → Regras
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {

    // Fotos de produtos: leitura pública, upload só autenticado
    match /produtos/{allPaths=**} {
      allow read: if true;
      allow write: if request.auth != null
                   && request.resource.size < 5 * 1024 * 1024
                   && request.resource.contentType.matches('image/.*');
    }
  }
}
